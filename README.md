Integrated Vendor Modules:

The vendor interface brings together the following modules from the team's development branches:

Vendor Dashboard: Displays store statistics, revenue, order information, product counts, and recent activity.
Vendor Products: Provides the interface for managing product listings and product information.
Vendor Orders: Provides the vendor interface for viewing and managing customer orders.
Vendor Inventory: Supports inventory-related operations and stock management.
Vendor Analysis: Provides business analytics and performance insights for vendors.
Offers & Coupons: Provides the interface for managing promotional offers and discount coupons.
Vendor Settings: Provides store preferences and notification settings.
Shared Vendor Layout: Uses a common navigation structure and layout across vendor pages to maintain a consistent user experience.

Branch Integration:

The vendor frontend was developed collaboratively across three feature branches:

vendor-dashboard

vendor-orders

vendor-inventory

The vendor-ui branch was used as an integration branch during the merge process
